My Journey as a Computer Science Engineering Student

Introduction

Starting B.Tech in Computer Science Engineering felt exciting and a little overwhelming. Now, as a second-year student at JSPM University, I can finally see how much I have grown.

Experience

In first year I wrote simple programs in C and learned how to think in steps. This year, Java introduced me to classes, objects and inheritance, and suddenly programs felt like real systems. Some bugs took hours to fix, but solving them was the most satisfying part.

Outside the classroom, college life in Pune — group studies, labs and projects with friends — taught me teamwork as much as coding. I also started exploring data structures, which changed how I think about storing and organising information.

Key Learnings

  • Consistent practice matters more than last-minute study.
  • Debugging patiently builds real problem-solving skills.
  • Explaining concepts to friends strengthens my own understanding.

Conclusion

I am still learning, but I am excited about what comes next. My goal is to become a capable software developer and build technology that genuinely helps people.

Java Programming Project – Student Management System

Problem Statement

Maintaining student records on paper is slow and error-prone. A simple program is needed to add, search, update and delete student details quickly.

Description

A console-based Java application that manages student records such as roll number, name and course. The user picks options from a menu, and the program stores records in memory (and can be extended to files or a database).

Java OOP: Classes & Objects ArrayList / Collections Scanner Input Exception Handling

Main Features

  • Add a new student
  • View all students
  • Search by roll number
  • Update student records
  • Delete student records
